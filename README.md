# ONG Projeto Front-End

Projeto desenvolvido como atividade prática da disciplina de Desenvolvimento Front-End para Web.

A aplicação representa uma ONG voltada ao atendimento de juvenis e adolescentes, apresentando informações sobre seus projetos e permitindo a interação do usuário por meio de uma interface responsiva.

## Tecnologias utilizadas

- HTML5: estruturação e organização semântica das páginas;
- CSS3: estilização, responsividade, Grid e Flexbox;
- JavaScript: interatividade, manipulação do DOM, navegação SPA, validações e componentes dinâmicos;
- Git: controle de versões do projeto;
- GitHub: armazenamento do repositório, gerenciamento de Issues, Milestones e Pull Requests.

## Funcionalidades

Entre as principais funcionalidades desenvolvidas estão:

- navegação no formato SPA;
- renderização dinâmica de conteúdo;
- validação de formulários;
- componentes de feedback e modal;
- layout responsivo;
- melhorias de acessibilidade;
- armazenamento de informações utilizando localStorage.

## Estrutura do projeto

O projeto está organizado em arquivos HTML, CSS e JavaScript, separando a estrutura da página, sua apresentação visual e o comportamento da aplicação.

Essa separação facilita a manutenção, organização e evolução do código.

## Pré-requisitos

Para executar o projeto é necessário possuir:

- navegador web atualizado;
- editor de código, como Visual Studio Code;
- Git instalado para utilização do controle de versões.

Não é necessária a instalação de dependências externas para executar a aplicação.

## Instalação e execução

Clone o repositório:

git clone URL-DO-REPOSITORIO

Acesse a pasta do projeto e abra o arquivo `index.html` utilizando um navegador ou um servidor local, como a extensão Live Server do Visual Studio Code.

## Build

O projeto utiliza HTML, CSS e JavaScript puro e, atualmente, não possui uma etapa específica de build ou compilação.

Os arquivos podem ser executados diretamente pelo navegador e preparados para publicação em um servidor web.

## Testes

Os testes da aplicação são realizados manualmente no navegador.

São verificados:

- funcionamento da navegação;
- validação dos formulários;
- responsividade;
- interações JavaScript;
- funcionamento dos componentes;
- acessibilidade básica da interface.

As ferramentas de desenvolvimento do navegador também são utilizadas para identificação de erros no console e análise do comportamento da aplicação.

## Versionamento

O projeto utiliza Git e GitHub para controle de versões, seguindo uma estratégia baseada em GitFlow.

As principais branches são:

- `main`: versão estável;
- `develop`: desenvolvimento e integração;
- `feature/`: desenvolvimento isolado de funcionalidades;
- `release/`: preparação de novas versões;
- `hotfix/`: correções urgentes.

Os commits seguem o padrão Conventional Commits, utilizando identificadores como `feat`, `fix`, `docs` e `chore`.

## Releases

O projeto utiliza Versionamento Semântico no formato:

MAJOR.MINOR.PATCH

Exemplo:

v1.0.0

Esse padrão permite identificar versões principais, novas funcionalidades e correções.
