# ONG Projeto Front-End

Projeto desenvolvido como atividade prática da disciplina de Desenvolvimento Front-End para Web.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Estrutura do projeto

A aplicação utiliza HTML para estruturação do conteúdo, CSS para estilização e responsividade e JavaScript para interatividade e manipulação do DOM.

## Versionamento

O projeto utiliza Git e GitHub para controle de versões, seguindo uma estratégia baseada em GitFlow.
